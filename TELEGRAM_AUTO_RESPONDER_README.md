# Telegram Auto Responder - Улучшенная Версия

Автоматический ответчик для личного аккаунта Telegram с уведомлениями оператору и возможностью отвечать на сообщения.

## ✨ Возможности

- ✅ **Автоответ вне рабочего времени** - отправляет сообщение сразу
- ✅ **Пересылка уведомлений оператору** - все сообщения перенаправляются на указанный аккаунт
- ✅ **Ответы через оператора** - отвечайте на пересланные сообщения
- ✅ **Поддержка медиафайлов** - работает с фото, видео, документами
- ✅ **Один автоответ в день** - не спамит пользователям
- ✅ **Защита секретных данных** - использует `.env` файл
- ✅ **Настраиваемое рабочее время** - Пн-Чт 9:00-17:30, Пт 9:00-17:00, Сб-Вс выходные
- ✅ **Автоматическая очистка памяти** - в полночь очищаются данные

## 📖 Как это работает

### Сценарий 1: Сообщение вне рабочего времени

1. Пользователь пишет вам в 22:00
2. **Автоответ** отправляется пользователю
3. **Уведомление** отправляется оператору (вам на другой аккаунт)
4. **Пересылается** оригинальное сообщение

```
[Пользователь] → [Ваш аккаунт] → [Автоответ]
                        ↓
                 [Оператор получает уведомление + переслан
ное сообщение]
```

### Сценарий 2: Ответ оператора

1. Оператор получает пересланное сообщение
2. **Отвечает** на него (Reply)
3. Бот отправляет ответ **оригинальному пользователю**
4. Оператору приходит **подтверждение**: "✅ Ответ успешно отправлен"

```
[Оператор] отвечает на пересланное → [Бот] → [Оригинальный пользователь]
```

### Сценарий 3: Медиафайлы

- Пользователь отправляет фото/видео → **Пересылается** оператору
- Оператор отвечает фото/видео → **Отправляется** пользователю
- ✅ Полная поддержка всех типов медиа

## 🔧 Настройка

По умолчанию в коде (`telegram_auto_responder.py:40-45`):

## 🐛 Устранение неполадок

### Ошибка: "The API ID/API Hash combination is invalid"

**Решение:** Проверьте правильность данных в `.env`

### Ошибка: "❌ Не найден оригинальный отправитель"

**Причины:**
1. Ответили не на пересланное сообщение
2. Данные очистились в полночь

**Решение:** Отвечайте только на **пересланные** сообщения (второе сообщение после уведомления)

### Не отправляет уведомления оператору

**Проверьте:**
1. `NOTIFICATION_USER_ID` не равен 0
2. ID правильный (проверьте через @userinfobot)
3. Проверьте логи на ошибки

### Бот не отвечает в рабочее время

**Это нормально!** Бот работает **только вне рабочего времени**. Чтобы он работал всегда, измените код:

```python
# В handle_new_message (строка 122):
if not self.is_working_hours():  # Убрать эту проверку
    await self.handle_after_hours_message(event)
```

На:

```python
# Работает всегда
await self.handle_after_hours_message(event)
```

## ⚙️ Автозапуск (Linux systemd)

```bash
sudo nano /etc/systemd/system/telegram-autoresponder.service
```

Вставьте:

```ini
[Unit]
Description=Telegram Auto Responder
After=network.target

[Service]
Type=simple
User=your_username
WorkingDirectory=/path/to/oneget
ExecStart=/usr/bin/python3 /path/to/oneget/telegram_auto_responder.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Запустите:

```bash
sudo systemctl daemon-reload
sudo systemctl enable telegram-autoresponder
sudo systemctl start telegram-autoresponder
sudo systemctl status telegram-autoresponder
```

## 📚 FAQ

**Q: Можно ли использовать без уведомлений оператору?**
A: Да, установите `NOTIFICATION_USER_ID=0` в `.env`

**Q: Работает ли с группами?**
A: Нет, только с личными сообщениями

**Q: Можно ли изменить рабочие часы?**
A: Да, измените `self.work_hours` в коде (строка 40-45)

**Q: Можно ли отправлять разные сообщения в разное время?**
A: Да, можно доработать код, добавив проверку времени в `auto_reply_message`

**Q: Нарушает ли это ToS Telegram?**
A: Автоматизация может нарушать правила. Используйте разумно и не спамьте.
