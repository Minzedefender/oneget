# Telegram Auto Responder

Автоматический ответчик для личного аккаунта Telegram. Бот автоматически отвечает на сообщения в следующих случаях:

1. **Вне рабочего времени** - отправляет сообщение сразу
2. **Если вы не ответили за 10 минут** - отправляет сообщение о занятости

## Возможности

- ✅ Автоответ вне рабочего времени (настраивается)
- ✅ Автоответ через N минут если не ответили вручную
- ✅ Настройка рабочих часов
- ✅ Кастомные сообщения для разных сценариев
- ✅ Автоматическая отмена автоответа при ручном ответе
- ✅ Работает только с личными сообщениями (игнорирует группы и ботов)

## Требования

- Python 3.8 или выше
- Telegram аккаунт
- API credentials от Telegram

## Установка

### 1. Клонируйте репозиторий (если еще не сделали)

```bash
git clone <your-repo>
cd oneget
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Получите API credentials

1. Перейдите на https://my.telegram.org
2. Войдите в свой Telegram аккаунт
3. Перейдите в "API development tools"
4. Создайте новое приложение
5. Сохраните **API ID** и **API Hash**

### 4. Настройте переменные окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите свои данные:

```env
API_ID=your_api_id_here
API_HASH=your_api_hash_here
PHONE_NUMBER=+1234567890

WORK_START_HOUR=9
WORK_END_HOUR=18
RESPONSE_DELAY_MINUTES=10

BUSY_MESSAGE=Извините, сейчас занят. Перезвоню при первой возможности.
AFTER_HOURS_MESSAGE=Сейчас не рабочее время. Отвечу в ближайшее рабочее время.
```

## Использование

### Первый запуск

При первом запуске Telegram попросит ввести код подтверждения:

```bash
python telegram_auto_responder.py
```

Следуйте инструкциям:
1. Введите код из SMS или Telegram
2. Если включена двухфакторная аутентификация - введите пароль

После успешной авторизации будет создан файл `telegram_session.session` - он сохранит вашу сессию для следующих запусков.

### Обычный запуск

```bash
python telegram_auto_responder.py
```

### Запуск в фоновом режиме (Linux/macOS)

```bash
nohup python telegram_auto_responder.py > telegram_bot.log 2>&1 &
```

### Остановка

Нажмите `Ctrl+C` в терминале или завершите процесс:

```bash
pkill -f telegram_auto_responder.py
```

## Настройка

### Переменные окружения (.env)

| Переменная | Описание | Пример |
|------------|----------|--------|
| `API_ID` | API ID от Telegram | `12345678` |
| `API_HASH` | API Hash от Telegram | `abcdef123456...` |
| `PHONE_NUMBER` | Номер телефона в международном формате | `+79991234567` |
| `WORK_START_HOUR` | Начало рабочего дня (час) | `9` |
| `WORK_END_HOUR` | Конец рабочего дня (час) | `18` |
| `RESPONSE_DELAY_MINUTES` | Задержка перед автоответом (минуты) | `10` |
| `BUSY_MESSAGE` | Сообщение когда занят | `Извините, сейчас занят...` |
| `AFTER_HOURS_MESSAGE` | Сообщение вне рабочего времени | `Сейчас не рабочее время...` |

### Рабочее время

По умолчанию:
- **Рабочие дни**: Понедельник - Пятница
- **Рабочие часы**: 9:00 - 18:00
- **Выходные**: Суббота и Воскресенье

Для изменения отредактируйте переменные в `.env` или константы в коде.

## Как это работает

### Сценарий 1: Сообщение вне рабочего времени

1. Кто-то пишет вам в 22:00
2. Бот **сразу** отправляет `AFTER_HOURS_MESSAGE`
3. Повторные сообщения от этого человека игнорируются до вашего ответа

### Сценарий 2: Сообщение в рабочее время

1. Кто-то пишет вам в 14:00
2. Бот **ждет 10 минут**
3. Если вы **НЕ** ответили за это время - отправляет `BUSY_MESSAGE`
4. Если вы **ответили** - автоответ отменяется

### Сценарий 3: Вы отвечаете вручную

1. Кто-то пишет вам
2. Запускается таймер на 10 минут
3. Вы отвечаете через 5 минут
4. Таймер отменяется, автоответ НЕ отправляется

## Безопасность

**ВАЖНО:**

1. **НИКОГДА** не публикуйте ваш `.env` файл
2. **НИКОГДА** не публикуйте `telegram_session.session`
3. Храните API credentials в секрете
4. Используйте двухфакторную аутентификацию в Telegram

Файл `.gitignore` уже настроен для игнорирования чувствительных данных.

## Устранение неполадок

### Ошибка авторизации

```
Error: The API ID/API Hash combination is invalid
```

**Решение:** Проверьте правильность `API_ID` и `API_HASH` в `.env`

### Не отправляет сообщения

**Проверьте:**
1. Бот запущен и подключен к Telegram
2. Рабочее время настроено правильно
3. Проверьте логи на наличие ошибок

### Отправляет сообщения самому себе

Бот **игнорирует** исходящие сообщения, поэтому это невозможно.

## Автозапуск (Linux systemd)

Создайте файл `/etc/systemd/system/telegram-autoresponder.service`:

```ini
[Unit]
Description=Telegram Auto Responder
After=network.target

[Service]
Type=simple
User=your_username
WorkingDirectory=/path/to/oneget
ExecStart=/usr/bin/python3 /path/to/oneget/telegram_auto_responder.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Запустите:

```bash
sudo systemctl daemon-reload
sudo systemctl enable telegram-autoresponder
sudo systemctl start telegram-autoresponder
```

Проверьте статус:

```bash
sudo systemctl status telegram-autoresponder
```
